# Accessibility and UX Review

Check:
- accessible label/name
- semantic role
- state/value announcement
- focus order
- keyboard behavior
- minimum touch target
- text scaling
- truncation/overflow
- contrast semantics
- non-color-only status
- loading state
- empty state
- error state
- disabled/loading controls
- destructive action clarity
- safety controls visibility
- privacy-safe copy
- design token/component compliance

Return:
1. blocking issues
2. accessibility failures
3. design-system violations
4. recommended fixes
5. test/manual QA steps
