# Trust & Safety Rules

- 18+ only.
- No anonymous or stranger direct messaging.
- Dating requires explicit opt-in.
- Block acts immediately and has system-wide precedence.
- Safety tools are free.
- Reporter identity is confidential.
- Exact location never reaches consumer clients.
- Verification is not a safety guarantee.
- Premium/organizer status never bypasses safety.
- Moderation evidence access is scoped.
